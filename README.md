# 학급 누가기록 도우미

담임교사가 학생 관찰·상담 내용을 기록하면, 학교생활기록부 **「행동특성 및 종합의견」 누가기록 문장**으로 다듬고 **나이스에 입력**까지 돕는 Windows 프로그램입니다. (전북교육청 나이스 기준)

## 내려받기

오른쪽 **Releases**에서 최신 버전의 `NugaRecordHelper.exe`를 내려받아, 원하는 폴더(예: `C:\누가기록`)에 두고 실행하세요.

- 설치가 필요 없습니다. Windows 10/11에 기본으로 들어 있는 .NET Framework 4로 실행됩니다.
- 처음 실행할 때 Windows SmartScreen이 「알 수 없는 게시자」라고 막으면 **추가 정보 → 실행**을 누르세요.
- 학생 기록·설정은 exe와 **같은 폴더**에 저장됩니다. 구글 드라이브·OneDrive 같은 동기화 폴더보다 **내 PC 로컬 폴더**를 권합니다.

## 주요 기능

- 기록하기: 날짜·시간·유형·학생을 고르고 메모나 키워드로 누가기록 문장 만들기 (AI 또는 규칙), 손글씨 메모 사진·PDF 읽기
- 학생별 누가기록: 문장 다듬기, AI 종합의견
- **나이스 로그인하기**(맨 위 단추) → **나이스에 입력하기**: 학교마다 다른 나이스 메뉴를 읽어 「행동특성및종합의견 → 누가기록」 화면을 찾아 열고, 학생 선택 → 행추가 → 날짜·내용 → 저장까지 자동. 이미 저장된 같은 기록은 다시 넣지 않습니다.
- 학생 명단: 나이스에 로그인만 하면 학급 명단을 자동으로 가져오기
- 다른 업무도움 프로그램이 띄운 나이스 창이 있으면 그 로그인을 같이 씀
- 업데이트: 맨 위 「업데이트」 단추로 새 버전 알림·업데이트 (학생 기록·설정은 그대로)

## 개인정보 보호

- 학생 이름은 가운데 글자를 0으로 바꿔 저장합니다 (홍길동 → 홍0동). 나이스에서 명단을 가져올 때도 브라우저 안에서 가린 뒤 가져옵니다.
- AI로 보내기 전 메모 속 이름을 가명으로 바꾸고, 보낼 내용을 미리 보여 줍니다. 사진·PDF는 이름을 직접 가린 사본만 보냅니다.
- 나이스 인증서 로그인은 선생님이 직접 합니다. 인증서 암호는 저장하지 않습니다.
- AI API 키는 이 PC·이 Windows 계정에서만 풀리도록 암호화해 저장합니다.
- 학기말·학년말 정리 기능으로 이 PC에 남은 기록을 지울 수 있습니다.

## 알아 두실 점

- 나이스는 학교망(또는 EVPN)에서만 접속됩니다.
- 나이스 자동 입력은 화면에서 학생·날짜·내용이 확인되지 않으면 저장하지 않고 멈춥니다. 입력 결과는 나이스 화면에서 꼭 한 번 확인하세요.
- 무료 Gemini API 키는 입력 내용이 서비스 개선에 쓰일 수 있어, 학생 기록에는 결제 등록한 키를 권합니다.
